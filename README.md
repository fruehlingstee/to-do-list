# TASKS — タスク管理アプリ

**v3.0** | [ライブデモ](https://fruehlingstee.github.io/to-do-list/)

シンプルで高機能なタスク管理Webアプリです。インストール不要でブラウザ上で動作し、PWAとしてホーム画面に追加することも可能です。

---

## 機能一覧

### タスク管理
- タスクの追加・編集・削除
- **優先度設定**（高 / 中 / 低）
- **期限日**の設定
- **メモ**の追加
- **サブタスク**の展開・管理
- ドラッグ＆ドロップによる並び替え

### 繰り返しタスク
自動リセット機能付きの繰り返し設定が可能です。

| 設定 | 内容 |
|---|---|
| 毎日 | 毎日リセット |
| 2日に1回 | 1日おきにリセット |
| 3日に1回 | 2日おきにリセット |
| 曜日を指定 | 指定した曜日にリセット |
| 毎月1日 | 月初にリセット |

### 並び替え
- 追加順
- 優先度順
- 期限日順
- 名前順
- 作成日順

### フィルタリング
- すべて
- 未完了
- 完了済み
- 期限超過
- 繰り返し

### その他
- **完了済みを一括削除**
- **全タスクリセット**
- **PWA対応**（ホーム画面へのインストール、オフライン利用可）

---

## 使い方

1. フォームにタスク名を入力し「追加」または `Enter` キーで登録
2. 必要に応じて優先度・期限日・繰り返し・メモを設定
3. タスクをクリックして完了/未完了を切り替え
4. ドラッグ＆ドロップで順番を変更
5. タスク右のメニューから編集・削除が可能

## インストール（PWA）

ブラウザのアドレスバーまたはメニューから「ホーム画面に追加」を選択することで、ネイティブアプリのように利用できます。

- **iOS**: Safari → 共有ボタン → 「ホーム画面に追加」
- **Android**: Chrome → メニュー → 「アプリをインストール」
- **Desktop**: アドレスバー右のインストールアイコンをクリック
